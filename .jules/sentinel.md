## 2026-07-17 - Bypassing Sanitization in Custom Table Cell SafeHtml Renditions
**Vulnerability:** Results from custom transformation pipes, such as `LlecoopProductBaseUnitTextPipe.transform()`, were interpolated directly into HTML strings passed to `DomSanitizer.bypassSecurityTrustHtml()` without prior HTML escaping. This allowed XSS payloads within `unit.base` fields to execute in the browser.
**Learning:** Bypassing security trust functions (e.g. `bypassSecurityTrustHtml`) completely disables Angular's built-in XSS defense for that template block. If any substring within the bypass statement is derived from user or administrator inputs (even if structured/typed or returned by pipes/services), it poses a severe injection risk.
**Prevention:** Always wrap all dynamic parameters and pipe outputs in `escapeHtml()` when interpolating them into a bypassed HTML block. Add an explicit `// SECURITY (XSS):` comment detailing the rationale behind the escaping to ensure other developers maintain security during future refactoring.

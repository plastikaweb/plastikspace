## 2026-07-04 - Stored XSS via trusted HTML sinks in table custom formatting configurations
**Vulnerability:** LlecoopProductBaseUnitTextPipe.transform() output was directly interpolated into HTML templates passed to DomSanitizer.bypassSecurityTrustHtml in LlecoopUserOrderDetailFormTableConfig and LlecoopUserOrderResumeTableConfig without sanitization, risking Stored XSS if unit.base properties are injected with malicious scripting.
**Learning:** Using Angular's DomSanitizer.bypassSecurityTrustHtml requires defensive escaping of all dynamic values embedded in the trusted HTML template. Developers can easily escape main fields (like name/info) but forget secondary dynamic segments, such as strings returned by helper pipes, which can still lead to vulnerability.
**Prevention:** Explicitly wrap all dynamic pipe or function results in escapeHtml() before embedding them in trusted templates, and add mandatory "// SECURITY (XSS):" comments explaining the security rationale.

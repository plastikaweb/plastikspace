## Description

The **Eco Store Auth Forgot Password Sent Feature** library provides the success confirmation view after a password recovery email has been sent to a user.

## Features

- **Confirmation UI**: Displays a clear success message and instructions for checking email and spam folders.
- **Navigation**: Includes a direct link to return to the login page.
- **Branded Layout**: Wraps the message in the `EcoStoreAuthContainerComponent` for consistent branding.

## Usage

This feature is typically navigated to automatically after a successful password recovery request.

## Running unit tests

Run `nx test forgot-password-sent` to execute the unit tests via Vitest.
